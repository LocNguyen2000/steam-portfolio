# Tower Defense (JavaScript)

This is a browser-based JavaScript conversion of the original JavaFX game. It uses the original map, tileset, tower icons, and sound effects from the Java project.

## Run

Open `index.html` in a modern browser. No install or build step is required.

## Controls

- Click **Start game** to begin.
- Choose a tower and click an empty map tile to place it.
- In Level 2, click **Tank Ally** or press `4`, then choose a road tile on the active route to summon an ally. Click another route tile to move it slowly; it stays put until you give another move command. It blocks enemies and independently aims its sniper-range cannon at nearby targets. The skill has a 30-second cooldown after deployment.
- Use `1`, `2`, or `3` to choose a tower, and `Esc` to cancel placement or skill targeting.
- Click **Sound on/off** to toggle audio; use **TD.** to return to the main menu.
