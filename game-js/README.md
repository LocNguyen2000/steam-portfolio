# Tower Defense (JavaScript)

This is a browser-based JavaScript conversion of the original JavaFX game. It uses the original map, tileset, tower icons, and sound effects from the Java project.

## Run

Open `index.html` in a modern browser. No install or build step is required.

## Controls

- Click **Start game** to begin.
- Choose a tower and click an empty map tile to place it.
- Use `1`, `2`, or `3` to choose a tower, and `Esc` to cancel placement.
- Click **Sound on/off** to toggle audio; use **TD.** to return to the main menu.
